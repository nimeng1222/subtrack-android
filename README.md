# SubTrack（订阅台账）

[![SubTrack CI](https://github.com/nimeng1222/subtrack-android/actions/workflows/ci.yml/badge.svg)](https://github.com/nimeng1222/subtrack-android/actions/workflows/ci.yml)

SubTrack 是一款面向个人用户的本地优先订阅管理 Android 应用。它帮助用户集中记录各类周期性支出，提前掌握扣费时间与真实花费，并在无需注册账号、默认不上传个人台账的前提下完成日常管理。

## 这是什么

SubTrack 用于管理视频、音乐、云存储、软件会员、话费套餐等各类订阅服务。用户可以记录每项服务的金额、扣费周期与到期时间，应用据此生成到期提醒、支出统计与账单日历。

## 解决什么问题

- 订阅分散在多个平台，续费时间与金额容易遗忘；
- 自动续费与试用转正缺乏提醒，可能产生非预期支出；
- 月度、年度支出缺乏统一口径，难以判断真实开销；
- 多数记账工具要求注册账号或上传数据，隐私成本较高。

## 核心功能

- **订阅台账**：支持周、双周、四周、月、季、半年、年、自定义天数与一次性共 9 种周期；可记录分类、金额、备注、自动续费、试用与单条提醒设置。
- **续费与状态管理**：支持续费确认、暂停与恢复、取消、过期、试用转正；长期未打开应用时可一次补记多期。
- **到期提醒**：本地通知，支持按条目设置提前天数；过期后按第 1、3、7 天补发，并提供通知权限、精确闹钟与电池优化的健康检查。
- **支出统计**：同时提供“本月将扣”“预计月均”“近 90 天实际月均”三种口径，每个数字均可展开查看计算方式与参与条目。
- **账单日历与趋势**：月历热力图、单日明细与近 6 个月趋势。
- **备份与迁移**：JSON 全量备份与恢复（损坏文件整体拒绝），CSV 导入导出（逐行容错、重复导入幂等）。
- **桌面小组件**：4×2 与 2×2 两种布局，展示预计月均、年度支出与近期到期。
- **可选增强**：深色模式、应用锁、预算与超支提醒、涨价提醒、订阅体检、多币种手动汇率。
- **可选联网能力**（默认关闭）：应用内检查更新、订阅模板、在线汇率、自带密钥（BYOK）的 AI 辅助分析，以及实验性的多设备同步。

## 适合谁

- 同时使用多项订阅服务、希望统一管理续费的个人用户；
- 关注月度与年度真实支出、需要可核对统计口径的用户；
- 重视隐私、不希望注册账号或把台账上传至第三方的用户；
- 需要离线可用、安装包轻量且无广告的 Android 用户。

## 隐私与本地化

- 无需注册账号，无广告；默认不上传个人订阅数据。
- 台账、流水与设置默认仅保存在本机（Room + DataStore）。卸载或清除数据前，可通过备份功能导出。
- 核心的记录、提醒与统计功能完全离线可用。
- 联网功能均为可选且默认关闭，仅由用户主动开启；相关请求不携带台账数据，AI 辅助分析仅发送用户预览的字段。
- AI 密钥使用 Android Keystore 加密保存，不写入备份文件。
- 不申请通讯录、短信、位置、相机等敏感权限；通知、精确闹钟与开机自启仅用于到期提醒。
- 应用内更新会校验版本、文件摘要与签名证书，仅在签名一致时交由系统安装器处理，不静默安装。

## 下载与兼容性

- 最新版本：v1.9.4（versionCode 61），通过 [GitHub Releases](https://github.com/nimeng1222/subtrack-android/releases/latest) 分发。
- 系统要求：Android 8.0（API 26）及以上。
- 技术栈：Kotlin、Jetpack Compose、Room、DataStore。
- 升级说明：包名固定为 `com.subtrack`；当前发布包使用开发签名，仅支持同签名覆盖安装，切换为正式签名前需先卸载旧版本。
